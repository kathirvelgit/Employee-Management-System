# 🏢 Employee Management System – Java

A simple Java-based Employee Management System developed to practice Object-Oriented Programming (OOP) concepts, including inheritance, polymorphism, method overriding, packages, access modifiers, and the `this`, `super`, and `final` keywords.

## ✨ Features

- 👨‍💼 Create an `Employee` class with employee ID, name, and salary.
- 🔒 Apply encapsulation using `private` and `protected` access modifiers.
- 🏗️ Initialize employee details using constructors and the `this` keyword.
- 👨‍💻 Create `Developer` and `Manager` subclasses using inheritance.
- 🔗 Use the `super()` keyword to call the parent class constructor.
- 🔄 Override the `calculateSalary()` method to calculate different bonuses.
- 🏢 Use a `static final` variable to store the company name.
- 🔐 Implement a `final` method to prevent method overriding.
- 🎭 Demonstrate runtime polymorphism using parent class references.
- 📦 Organize classes into separate packages.

## 📋 Project Functionality

### Employee Class
- Stores employee ID, name, and salary.
- Initializes employee details using a constructor.
- Calculates the basic salary.
- Displays company information using a final method.

### Developer Class
- Inherits properties from the `Employee` class.
- Uses `super()` to initialize employee details.
- Overrides `calculateSalary()` to include a developer bonus.

### Manager Class
- Inherits properties from the `Employee` class.
- Uses `super()` to initialize employee details.
- Overrides `calculateSalary()` to include a manager bonus.

### Main Application
- Creates `Developer` and `Manager` objects.
- Uses `Employee` references to demonstrate runtime polymorphism.
- Displays employee details, company name, and calculated salaries.
